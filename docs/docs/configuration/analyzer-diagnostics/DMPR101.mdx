# DMPR101

DomainMapper could not find an accessible constructor, complete writable-property path, or configured target factory that can be satisfied from the source contract.

Construction is fail-closed. The diagnostic is also reported when a writable or required target member has no matching source member, a matched target member is inaccessible from the consumer assembly, or a required nested conversion cannot be generated. Required and `init` properties are populated in an object initializer. Other valid mapping methods in the same mapper are still emitted so their diagnostics remain independently actionable.
