# Installation

## Requirements

- .NET 8+ or .NET Framework 4.x.
- C# language version 9 or later
- Roslyn 4.8 or later

:::warning
DomainMap is experimental and is not currently published to NuGet. Build and consume it from source while the API evolves.
:::

## Build from source

```bash
dotnet restore DomainMap.slnx -p:HUSKY=0
dotnet build DomainMap.slnx -p:HUSKY=0 --no-restore
dotnet pack src/DomainMap/DomainMap.csproj -c Release -p:HUSKY=0
```

Reference the generated package from a local NuGet source, or use project references while developing DomainMap and its consumer together.

```xml
<ItemGroup>
  <ProjectReference Include="../DomainMap/src/DomainMap/DomainMap.csproj"
                    OutputItemType="Analyzer"
                    ReferenceOutputAssembly="false" />
  <ProjectReference Include="../DomainMap/src/DomainMap.Abstractions/DomainMap.Abstractions.csproj" />
</ItemGroup>
```

### Preserving the attributes at runtime

DomainMap removes the attribute references at compile time by default (they have the `ConditionalAttribute`).
If you want to preserve the attribute references at runtime
you can set the MSBuild variable `DomainMapAbstractionsScope` to `runtime`.

```xml
<PropertyGroup>
  <DomainMapAbstractionsScope>runtime</DomainMapAbstractionsScope>
</PropertyGroup>
```

:::info
When preserving the attribute usages, the DomainMap package reference needs to include the runtime assets.  
Make sure `ExcludeAssets` on the `PackageReference` does not include `runtime`.
:::

:::info
`DomainMapAbstractionsScope` only works in projects referencing `DomainMap` directly.
Alternatively you can set a constant `DOMAINMAP_ABSTRACTIONS_SCOPE_RUNTIME`:

```xml
<PropertyGroup>
  <DefineConstants>$(DefineConstants);DOMAINMAP_ABSTRACTIONS_SCOPE_RUNTIME</DefineConstants>
</PropertyGroup>
```

:::
