# Security Policy

Please report suspected vulnerabilities privately through the repository's GitHub Security Advisory flow. Do not open a public issue before a fix or mitigation is available.

Include the affected DomainMapper version, generated code or mapper declaration, reproduction steps, impact, and any proposed mitigation. Security reports may cover the source generator, analyzer diagnostics, generated code, packaging, or documentation.

DomainMapper is currently experimental; no release line has long-term support yet.
